# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- **Be kind and patient.** Many people here are learning, and every question is welcome.
- **Critique ideas and code, not people.**
- **Never harass anyone.** That includes insults, discriminatory jokes, unwelcome sexual attention, doxxing and sustained disruption.
- These rules apply in issues, pull requests, discussions and anywhere else you represent the project.

## Reporting

Report unacceptable behaviour privately to the maintainer through [GitHub](https://github.com/matheussartori). If you prefer, open a private security advisory on this repository and mark it "conduct". Every report is reviewed and kept confidential.

Maintainers may remove comments, commits or contributions, and may ban contributors temporarily or permanently, following the enforcement guidelines of the Contributor Covenant.
