O **algo** é um site gratuito para aprender algoritmos e estruturas de dados. Ao usá-lo, você concorda com os termos abaixo.

## O que o site faz com o seu código

- Todo código que você escreve nos exercícios roda **no seu navegador**, num Web Worker isolado, com limite de tempo. Nada é enviado a um servidor.
- O rascunho de cada exercício fica salvo no `localStorage` do seu navegador, para você não perder o que escreveu. Para apagar, limpe os dados do site no navegador.

## Privacidade

- Não há conta, login, cookies de rastreamento nem ferramentas de analytics.
- As fontes vêm do Google Fonts e do Fontshare. Ao carregar a página, o seu navegador faz pedidos a esses serviços, que recebem o seu endereço IP, como em qualquer site que usa fontes deles.
- O provedor de hospedagem pode registrar dados técnicos de acesso (IP, data, página pedida) em logs de servidor, para segurança e operação.
