Numa biblioteca enorme, cada livro tem um número de identificação único, e a estante está **ordenada** por esse número. A bibliotecária Jane precisa achar o livro que um leitor pediu.

Retorne o índice do livro, ou `-1` se ele não existir.

:::caution[Use busca binária]
Os testes ocultos usam arrays grandes e contam quantos elementos sua função lê. Uma busca linear não passa.
:::

```ts title="Exemplo"
const libraryBooks = [102, 205, 308, 410, 523, 636, 749, 852, 965, 1078]
findBookIndex(libraryBooks, 410) // 3
```
