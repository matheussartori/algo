Uma nave explora uma galáxia distante guiada pelos sinais de corpos celestes. Dado um array **ordenado** de frequências e uma frequência alvo, encontre o índice da frequência mais próxima do alvo.

Em caso de empate, retorne o **menor** índice. O array sempre tem pelo menos um elemento.

:::caution[Use busca binária]
Os testes ocultos usam arrays grandes e contam quantos elementos sua função lê. Uma busca linear não passa.
:::

```ts title="Exemplo"
const beaconFrequencies = [100, 200, 300, 400, 500]
findClosestFrequency(beaconFrequencies, 350) // 2 (300 e 400 empatam; fica o menor índice)
```
