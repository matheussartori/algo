Numa padaria movimentada, cada doce tem um código, e a vitrine está em **ordem alfabética** de código. A confeiteira Sarah precisa achar um doce específico.

Retorne o índice do doce, ou `-1` se ele não estiver na vitrine.

:::caution[Use busca binária]
Os testes ocultos usam arrays grandes e contam quantos elementos sua função lê. Uma busca linear não passa.
:::

```ts title="Exemplo"
const bakeryPastries = ['Croissant2022', 'CroissantAlmond', /* … 50 doces … */ 'SconeVanilla']
findPastryIndex(bakeryPastries, 'SconeLemon') // 46
```
