Num laboratório de genética, os cientistas mantêm um catálogo **ordenado** de sequências de DNA associadas a mutações conhecidas. Cada sequência é uma string com as letras A, C, G e T.

Retorne `true` se a sequência analisada está no catálogo, ou `false` caso contrário.

:::caution[Use busca binária]
Os testes ocultos usam arrays grandes e contam quantos elementos sua função lê. Uma busca linear não passa.
:::

```ts title="Exemplo"
const dnaSequences = ['ACGT', 'ATCG', 'CGTA', 'GTAC', 'TACG']
searchForMutation(dnaSequences, 'ATCG') // true
```
