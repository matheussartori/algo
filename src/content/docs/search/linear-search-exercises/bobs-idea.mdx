Você é professor e recolheu as propostas de projeto da turma. A proposta do Bob tem ideias essenciais para o sucesso do projeto e você precisa encontrá-la para revisar.

Retorne o índice da proposta cujo `name` é o procurado, ou `-1` se não existir.


```ts title="Exemplo"
const projectProposals = [
  { name: 'Alice', idea: 'Idea A' },
  { name: 'Bob', idea: 'Idea B' },
  { name: 'Charlie', idea: 'Idea C' },
]
findProposalIndexByName(projectProposals, 'Bob') // 1
```
