O Capitão Tom enterrou seu tesouro atrás de uma árvore com um número específico de galhos, indicado no mapa. Nesta ilha, cada árvore tem uma quantidade diferente de galhos. Dado um array com o número de galhos de cada árvore, encontre o índice da árvore com a quantidade indicada.

Se nenhuma árvore tiver essa quantidade, retorne `-1`.


```ts title="Exemplo"
const branchesOnTrees = [2, 4, 6, 8, 10]
findTreeIndexByBranches(branchesOnTrees, 6) // 2
```
