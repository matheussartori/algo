Você está montando uma cesta de frutas para um piquenique, mas perdeu a laranja no meio dela. Sua amiga Sarah é alérgica a laranja e não pode ajudar a procurar. Acha essa laranja logo!

Retorne o índice da **primeira** laranja, ou `-1` se não houver nenhuma.


```ts title="Exemplo"
const fruitBasket = ['apple', 'banana', 'grape', 'orange']
findOrangeIndexInBasket(fruitBasket, 'orange') // 3
```
