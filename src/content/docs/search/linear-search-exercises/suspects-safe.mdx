Você é detetive e investiga uma série de furtos. Você tem a lista de suspeitos e o conteúdo do cofre de cada um. Encontre o suspeito cujo cofre tem **exatamente** os itens roubados, na mesma ordem.

Retorne o índice do suspeito, ou `-1` se nenhum cofre bater.


```ts title="Exemplo"
const suspectsData = [
  { id: 1, safeContents: [10, 20, 30] },
  { id: 2, safeContents: [40, 50, 60] },
  { id: 3, safeContents: [70, 80, 90] },
]
findSuspectIndexBySafeContents(suspectsData, [40, 50, 60]) // 1
```
