Explorando uma caverna antiga, você encontrou câmaras com símbolos misteriosos nas paredes. A caverna é representada por uma matriz: cada **linha** é uma câmara e cada número é um símbolo dela.

Retorne o índice da câmara (a linha) que contém o símbolo procurado, ou `-1` se ele não estiver na caverna.


```ts title="Exemplo"
const caveLayout = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9],
]
findChamberIndexBySymbol(caveLayout, 5) // 1
```
