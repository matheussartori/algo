In a busy bakery, every pastry has a code, and the display is in **alphabetical order** by code. Baker Sarah needs to find a specific pastry.

Return the index of the pastry, or `-1` if it is not on display.

:::caution[Use binary search]
Hidden tests use large arrays and count how many elements your function reads. A linear scan will not pass.
:::

```ts title="Example"
const bakeryPastries = ['Croissant2022', 'CroissantAlmond', /* … 50 pastries … */ 'SconeVanilla']
findPastryIndex(bakeryPastries, 'SconeLemon') // 46
```
