In a genetics lab, scientists keep a **sorted** catalog of DNA sequences linked to known mutations. Each sequence is a string made of the letters A, C, G and T.

Return `true` if the analyzed sequence is in the catalog, or `false` otherwise.

:::caution[Use binary search]
Hidden tests use large arrays and count how many elements your function reads. A linear scan will not pass.
:::

```ts title="Example"
const dnaSequences = ['ACGT', 'ATCG', 'CGTA', 'GTAC', 'TACG']
searchForMutation(dnaSequences, 'ATCG') // true
```
