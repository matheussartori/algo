A spacecraft explores a distant galaxy guided by signals from celestial bodies. Given a **sorted** array of frequencies and a target frequency, find the index of the frequency closest to the target.

On a tie, return the **smallest** index. The array always has at least one element.

:::caution[Use binary search]
Hidden tests use large arrays and count how many elements your function reads. A linear scan will not pass.
:::

```ts title="Example"
const beaconFrequencies = [100, 200, 300, 400, 500]
findClosestFrequency(beaconFrequencies, 350) // 2 (300 and 400 tie; keep the smaller index)
```
