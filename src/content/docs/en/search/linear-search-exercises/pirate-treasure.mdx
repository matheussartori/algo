Captain Tom buried his treasure behind a tree with a specific number of branches, as shown on the map. On this island, every tree has a different number of branches. Given an array with the number of branches of each tree, find the index of the tree with the given count.

If no tree has that count, return `-1`.


```ts title="Example"
const branchesOnTrees = [2, 4, 6, 8, 10]
findTreeIndexByBranches(branchesOnTrees, 6) // 2
```
