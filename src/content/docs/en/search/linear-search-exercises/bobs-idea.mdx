You are a teacher and collected the class's project proposals. Bob's proposal has ideas that are key to the project's success, and you need to find it to review it.

Return the index of the proposal whose `name` matches, or `-1` if there is none.


```ts title="Example"
const projectProposals = [
  { name: 'Alice', idea: 'Idea A' },
  { name: 'Bob', idea: 'Idea B' },
  { name: 'Charlie', idea: 'Idea C' },
]
findProposalIndexByName(projectProposals, 'Bob') // 1
```
