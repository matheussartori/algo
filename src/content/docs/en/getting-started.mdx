Every topic follows the same loop. It is not arbitrary: each stage comes from research on how people learn.

1. **Intuition.** A real-world problem and the idea behind the solution.
2. **Visualization.** The algorithm runs step by step, with the current line of code highlighted.
3. **Prediction.** You decide the next step before you see it. Studies show visualizations only really teach when you interact with them, not when you just watch.
4. **Practice.** Exercises with tests. Some tests are hidden, so you think about the hard cases instead of memorizing the answer.
5. **Review.** Quick questions to answer from memory. Active recall sticks better than re-reading.

## Exercises

- Pick **TypeScript** or **JavaScript** at the top of the editor. Your choice and your code are saved in this browser.
- Press **⌘/Ctrl + Enter** to run the tests.
- Stuck? Try for about 20 minutes, then ask for a **hint**. Hints go from a small nudge to almost the answer.
- The **solution** unlocks only after you run the tests at least once. If you look, close it and rewrite it from memory.

Your code runs in a **Web Worker**, separate from the page: an infinite loop freezes nothing and is stopped after 3 seconds.
